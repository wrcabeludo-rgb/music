# Минус: репетиция по стемам (PWA)

Загружаете свой аудиофайл, приложение разделяет его на 4 дорожки (вокал, ударные, бас, музыка)
прямо в браузере (модель HTDemucs, ONNX Runtime Web, WebGPU) и показывает микшер:
фейдер громкости, Mute и Solo для каждой дорожки, перемотка, повтор отрезка A–B.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в корень содержимое этой папки (index.html, app.js, vendor/ и т.д.).
2. Settings → Pages → Source: Deploy from a branch → ветка main, папка / (root).
3. Откройте https://<имя>.github.io/<репозиторий>/ (нужен HTTPS, Pages его дает).
4. Chrome/Android: меню → «Установить приложение». iPhone: Safari → «Поделиться» → «На экран Домой».

Файл vendor/ort/ort-wasm-simd-threaded.jsep.wasm весит около 28 МБ. Это меньше лимита GitHub (100 МБ на файл).

## Как это работает
- Модель (~172 МБ) скачивается с Hugging Face при первой обработке и сохраняется в Cache Storage устройства.
- Стемы хранятся в IndexedDB (16-бит PCM, см. ограничения), настройки микса в localStorage.
- Для переноса на свой сервер поменяйте MODEL_URL в app.js на свой хостинг модели.

## Ограничения
- Без заголовков COOP/COEP (GitHub Pages) WASM работает в один поток. Без WebGPU разделение очень медленное.
- Размер сохраненных стемов: около 42 МБ на каждую 4 минуты трека на дорожку (около 170 МБ на песню).
- Смена темпа без смены тональности не реализована.
