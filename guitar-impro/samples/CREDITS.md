# Записи гитары

**Нейлон** (`nylon/`) — из набора [tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments) (Nicholas Brosowsky), npm-пакет `tonejs-instrument-guitar-nylon-mp3` (лицензия пакета — MIT).

**Электрогитара с перегрузом** (`drive/`) — из SoundFont FluidR3_GM (Frank Wen, лицензия MIT), npm-пакет `soundfont-for-samplers` (MIT).

Файлы перекодированы (моно, обрезка до 3–4 секунд) и названы номером ноты MIDI. Фактическая высота каждой записи измерена и учтена в `audio.js`.
