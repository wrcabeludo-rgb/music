# Музыкальные приложения

## Гитара: аккорды и импровизация

Тренажёр для гитариста: аппликатуры аккордов (трезвучия по наборам струн, shell, drop 2 / drop 3, аккорды с надстройками и альтерациями) во всех тональностях, 25 блюзовых, роковых и джазовых фраз с табулатурой и звуком, справочник по теории и упражнения: «Повтори за мной» (приложение играет фразу, вы повторяете; проверка нот через микрофон, смена тональностей по квартам), подложки для импровизации, слуховой тренажёр аккордов, аккорды по диаграмме, формулы. На главной — метроном (акценты, размеры, дробление доли, тап-темп) и тюнер.

Папка: [`guitar-impro/`](guitar-impro/)
Сайт: https://wrcabeludo-rgb.github.io/music/guitar-impro/

Звук — записи нейлоновой гитары, электрогитары с перегрузом и фортепиано для аккомпанемента (громкость аккомпанемента регулируется) (источники и лицензии: [`guitar-impro/samples/CREDITS.md`](guitar-impro/samples/CREDITS.md)), есть запасной синтез.

Устанавливается на телефон как приложение (PWA) и работает без интернета. При изменении файлов приложения увеличивайте `CACHE` в `guitar-impro/sw.js`. Проверка аппликатур и фраз: `node guitar-impro/tools/check.js`.

## Ноты из голоса

Записывает нотами одноголосную мелодию (например, вокальную партию) из аудиофайла или с микрофона: высота и длительность нот, темп, размер, затакт, тональность. Ноты можно поправить, прослушать вместе с записью и сохранить в MusicXML, MIDI, ABC или PDF. Всё считается на устройстве.

Папка: [`notes/`](notes/)
Сайт: https://wrcabeludo-rgb.github.io/music/notes/

Проверка распознавания: `node notes/tools/check.js`.

## Тексты по шаблонам

Тренажёр для написания текстов песен. Шаблон задаёт, сколько слогов в каждой строке, с каких слов начинаются строки, какие строки готовые (рефрен) и что с чем рифмуется; есть и шаблоны-«рамки» — конструкции, которые надо заполнить своими словами. Пять исходных шаблонов плюс генератор новых по тем же правилам (короткие строки с опорными словами, длинные строки с парами «ты… / я…» и рефреном, рамки). При письме приложение считает слоги, проверяет начало строки и рифму с нужной строкой. Тексты сохраняются в браузере, их можно скопировать или отправить.

Папка: [`lyrics/`](lyrics/)
Сайт: https://wrcabeludo-rgb.github.io/music/lyrics/

Устанавливается на телефон как приложение (PWA) и работает без интернета. При изменении файлов приложения увеличивайте `CACHE` в `lyrics/sw.js`. Шаблоны и генератор — в `lyrics/templates.js`.
